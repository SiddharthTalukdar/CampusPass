## 🛠️ Tools & Technologies Used
- **Backend Framework:** FastAPI (Python)[cite: 3]
- **Database:** SQLite & SQLAlchemy ORM[cite: 3]
- **Authentication:** JWT (JSON Web Tokens) & Argon2/Bcrypt[cite: 3]
- **Validation:** Pydantic Schemas[cite: 3]
- **Documentation:** Interactive OpenAPI / Swagger UI
- **Server:** Uvicorn ASGI Server[cite: 5]

## 🌟 Features Covered
- **User Authentication:** Student registration, login, and protected admin login[cite: 1, 17].
- **Event Management:** Admin capabilities to create and view campus events[cite: 2, 17].
- **Ticketing & Booking:** Booking pipelines with automated dynamic pricing calculations[cite: 3].
- **Pass Verification:** QR code generation for digital student event passes[cite: 3].
